# 统一网管前端架构与发布约定

## 职责与设计

本模块是 Vue 3 + Vite 的单页应用，展示 FTTH/HFC、采集监控、Radius、AIOps、系统审计和基础设施监控。浏览器只访问 233 的统一入口，不直连 236、20、212、213 或数据库。

## 接口与端口

| 路径/端口 | 方向 | 用途 |
| --- | --- | --- |
| `https://233:5772/` | 用户 → 233 | 网管 SPA 统一入口 |
| `/wx/api/netops2026/*` | 浏览器 → 233 BFF | 业务、采集、Radius、AIOps 和基础设施数据 |
| `7001` | 233 Nginx → 本机 BFF | 仅监听回环，不向浏览器暴露 |

## 数据库与安全

前端无数据库账号、无服务密钥。认证由 233 BFF 的 JWT/权限控制完成；构建输出 `dist/` 和本地 `node_modules/` 不提交。基础设施拓扑以 BFF 探针数据为准，当前入口明确为 **233:5772**。

## 验证

```bash
npm ci
npm run build
```

部署后验证 `/`、`/infrastructure`、采集、Radius 和 AIOps 页面通过 5772 正常加载。
